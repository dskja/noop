# NOOP v9.0.1 — Strand polish

A focused iOS polish release that keeps the v5 Strand hubs from drifting apart across platforms.

## Sources parity fix

- The iOS **Sources** tab now labels the body group **"Health"** to match macOS and Android. The expand/collapse preference is still stored under the stable `Body` key, so existing settings are preserved.
- The **Sources** tab icons have been aligned with the macOS sidebar `NavItem` icons:
  - **Compare** now uses `chart.line.uptrend.xyaxis`.
  - **Trends** now uses `chart.xyaxis.line` (they were swapped).
  - **Stress**, **Breathe**, **Data Sources** and **Support** now use their canonical SF Symbols.

This release carries forward the entire v9.0.0 Strand redesign underneath; it is a non-empty bug-fix/polish update.
